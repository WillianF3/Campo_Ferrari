# 🎯 Campo Ferrari Airsoft

Site oficial do Campo Ferrari Airsoft, localizado em Videira, Santa Catarina, Brasil.

## 🚀 Sobre o projeto

Plataforma web desenvolvida para apresentar o campo, organizar partidas e facilitar o gerenciamento de participantes e reservas.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- Git e GitHub

## ⚙️ Funcionalidades

- Interface responsiva
- Listas de participantes
- Gerenciamento de partidas
- Área administrativa
- Integração com WhatsApp
- Localização pelo Google Maps
- Galeria de imagens
- Informações sobre equipamentos e serviços
